# Controls — EarthBound PC Port COOP

Use a keyboard and mouse, or a compatible controller. The PlayStation names below refer to button positions; Xbox, Switch and generic controllers use the equivalent positions. Customize bindings in **F1 → Controls**.

## Keyboard

| Input | Action |
|---|---|
| WASD / Arrow keys | Move and navigate menus |
| E / Enter | Interact or confirm |
| Q / Esc / Ctrl | Back in menus |
| Tab | Personal menu |
| Shift + movement | Run (+23%, optional) |
| F1 | Options and gameplay settings |
| F2 | Saves |
| F3 / F4 | Choose a quicksave to save / load |
| Comma / Period | Zoom out / in |
| Hold + / Hold - | Fast-forward / rewind |
| T | P1 teleports to P2 in co-op |

## Mouse

Hold the left button in a direction to walk. Click a character or object to approach and interact. Left click selects and confirms; right click opens the personal menu or goes back. Use the wheel to navigate menu choices and battle targets. Release and click again to advance dialogue after selecting an option. Mouse controls are optional in Gameplay.

## Controller — PlayStation layout

| Input | Action |
|---|---|
| D-pad / Left stick | Move and navigate |
| Hold Cross (X) + movement | Run |
| Cross (X) | Confirm menus and dialogue |
| Square | Talk, inspect and interact |
| Circle | Personal menu / Back |
| Triangle | Party HP, PP and money |
| Cross (X) + R1 | Photo pose in the overworld |
| L3 | Teleport to the other player in co-op |
| P2 R3 | Cycle Mess’s clothing colors |
| P2 Select / Share | Leave the co-op session |

In **F1/F2**, Cross always confirms and Circle always goes back, including when gameplay controls are customized. L1/R1 switch tabs. Either stick click makes Mr. Saturn react. Illustrated control maps and remapping are available in **F1 → Controls**.

Enable experimental co-op in **F1 → Gameplay**, then press Start/Options on the second controller and accept the in-game prompt. Features can depend on the installed build and selected preferences.
