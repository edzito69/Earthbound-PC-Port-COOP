# EarthBound PC Port COOP - 4.5.0

An unofficial native adaptation for Windows, Linux, macOS and Android, based
on Brian Pugh and contributors' EarthBound C implementation and the community
work credited in [CREDITS.md](CREDITS.md). Directed by Edzito with extensive
OpenAI Codex assistance in implementation, debugging, tests and packaging.


## Install

Download a release and extract the entire package. Desktop players must add
their own unmodified EarthBound USA ROM to **Put your rom here - Coloque sua rom aqui**.
Windows: open `Port PC/EarthBound PC.exe`; Linux: run `Port Linux/earthbound-pc`;
macOS: open `Port Mac/EarthBound PC.app`. Keep all accompanying libraries and
`adaptacao.ebpatch`. Android: install the APK and select your own ROM with
the document picker. No ROM is supplied or downloaded.

F1 / Mr. Saturn opens options; F2 opens saves. See [controls](CONTROLS.md).
COOP and Online remain experimental; keep backups. The latest changes are
listed in [CHANGELOG.md](CHANGELOG.md). Native Windows automated tests pass;
physical Android, Linux and macOS execution is not verified on this machine.
Read the [Online precautions](docs/ONLINE-SAFETY-EN.md) before hosting.

## What this repository contains

This is a distribution repository: runtimes, installation notes, controls,
credits and dependency notices. It is not a complete buildable source checkout.
The upstream code and its revision are linked in CREDITS.md. Original authors
retain their authorship; AI assistance does not replace their contributions.
Thank you to the original developers, modders, translators, researchers,
testers and players who keep EarthBound accessible. — Edzito

GitHub's automatic Source code downloads contain the repository files.
This prepared tree excludes personal ROMs, saves, preferences, keys, build
logs, dependency caches and private generated game-resource headers.
Keep the original third-party notices in each runtime's licenses folder.
English and Brazilian Portuguese are available; Spanish/Chinese are not
integrated.
