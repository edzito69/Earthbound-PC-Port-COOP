EarthBound PC COOP — Version 3.5

An unofficial fan-made hybrid port and experimental modification of EarthBound (SNES), aiming to deliver the definitive way to experience this incredible RPG on modern computers!

Developed with love by Edzito, this project brings EarthBound to Windows, Linux, and macOS, combining contributions from existing community repositories with new features, modernized controls, and quality-of-life improvements.

The project features Brazilian Portuguese support, 4K widescreen resolution, 60 FPS, save states, rewind, fast-forward, running, customizable controller support, keyboard and mouse controls, chapter selection, and a new "Where to Go?" feature to help players remember their next main story objective.

The biggest addition is an experimental local CO-OP mode!

Two players can explore the world independently, interact with NPCs, access individual menus, and participate in separate or shared battles. Player 2 controls Mess, an alternate version of Ness with his own stats, inventory, equipment, and progression.

When players move apart, the game dynamically switches to split-screen, allowing both to continue their adventures without interrupting each other.

Please note that this is still an experimental project. Some features may be incomplete, and bugs or unexpected behavior may occur. Community testing, feedback, and bug reports are greatly appreciated!
